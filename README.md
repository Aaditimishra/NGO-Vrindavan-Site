# 🪷 वरदान श्री गोलोक धाम सेवा ट्रस्ट — Website + CMS

वृन्दावन स्थित ट्रस्ट के लिए बनाई गई पूर्ण वेबसाइट, जिसका सारा कंटेंट (संपर्क विवरण सहित)
बिना कोडिंग जाने, एडमिन पैनल से बदला जा सकता है।

---

## 🚀 वेबसाइट कैसे चलाएँ

```bash
cd NGO-Site
npm install      # sirf pehli baar
npm start
```

फिर ब्राउज़र में खोलें:

| क्या | पता |
|---|---|
| वेबसाइट | http://localhost:3400 |
| एडमिन पैनल | http://localhost:3400/admin |

**पहला लॉगिन:** यूज़रनेम `admin`. शुरुआती पासवर्ड सर्वर पहली बार चलाने पर
टर्मिनल में छप जाता है (और `data/config.json` में hash के रूप में सुरक्षित रहता है)।
Vercel पर इसे `ADMIN_PASSWORD` environment variable से तय करें।

> ⚠️ लॉगिन करते ही **⚙️ सेटिंग्स → पासवर्ड बदलें** ज़रूर करें।

पोर्ट बदलना हो तो: `PORT=8080 npm start`

एडमिन पैनल (`/admin`) में बाईं ओर 14 अनुभाग हैं — **वेबसाइट का लगभग हर शब्द और चित्र** यहाँ से बदला जा सकता है:

- **🏛️ ट्रस्ट की जानकारी** — नाम, स्थापना वर्ष, लोगो, पंजीकरण/PAN/80G, सोशल मीडिया, फुटर
- **☎️ संपर्क विवरण** — फोन, व्हाट्सएप, ईमेल, पता, समय, Google Map
  *(यहाँ बदलते ही पूरी वेबसाइट के हेडर, फुटर एवं संपर्क पृष्ठ पर अपने आप बदल जाता है)*
- **🏠 मुख्य पृष्ठ** — स्लाइडर, स्वागत टेक्स्ट, आँकड़े, उद्धरण, दान बैनर
- **📖 हमारे बारे में** — कहानी, ध्येय, मूल्य, समयरेखा, संस्थापक, टीम
- **🤲 सेवाएँ** · **🖼️ गैलरी** · **🎉 उत्सव** · **📰 ब्लॉग** — जोड़ें / हटाएँ / क्रम बदलें
- **❤️ दान** — राशि कार्ड, बैंक खाता, UPI ID एवं QR
- **🙋 स्वयंसेवक** — सेवा के अवसर (फॉर्म का ड्रॉपडाउन अपने आप अपडेट होता है)
- **💬 प्रशंसापत्र व FAQ**
- **📬 प्राप्त संदेश** — संपर्क फॉर्म से आए संदेश (व्हाट्सएप बटन सहित)
- **📝 स्वयंसेवक आवेदन** — पंजीकरण फॉर्म से आए आवेदन
- **⚙️ सेटिंग्स** — पासवर्ड बदलें

### काम की बातें
- **सहेजना ज़रूरी है** — बदलाव करने के बाद नीचे 💾 **सहेजें** दबाएँ (या `Ctrl/Cmd + S`)
- **चित्र बदलना** — किसी भी चित्र के नीचे *"⬆ नया अपलोड करें"* से अपने फोन/कंप्यूटर की फोटो लगाएँ
- **सूची में जोड़ना/हटाना** — हर सूची के नीचे *"+ नया जोड़ें"*, और हर आइटम पर ↑ ↓ 🗑 बटन
- हर बार सहेजने से पहले पुरानी प्रति अपने आप `data/backups/` में सुरक्षित हो जाती है (अंतिम 20)

| टेस्ट | क्या जाँचता है |
|---|---|
| `e2e-test.js` | हर पेज, लॉगिन सुरक्षा, गैलरी/सेवा/ब्लॉग/उत्सव में जोड़ना-हटाना-क्रम बदलना, दोनों फॉर्म, इनबॉक्स, चित्र अपलोड, पासवर्ड |
| `admin-ui-test.js` | असली Chrome में एडमिन पैनल — 🗑 हटाएँ, पुष्टि विंडो, ↑↓, सहेजना, इनबॉक्स, मोबाइल साइडबार |
| `responsive-test.js` | 9 पेज × 5 स्क्रीन (360/390/768/1280/1440) — horizontal overflow एवं छोटे tap target |

(`CHROME_PATH` से रास्ता बदला जा सकता है) — कोई अतिरिक्त npm package नहीं चाहिए।

## 🌐 इंटरनेट पर लाइव करने के लिए

### Vercel (जो इस प्रोजेक्ट के लिए तैयार है)

रिपॉज़िटरी Vercel पर import करें — `vercel.json` पहले से मौजूद है, कोई सेटिंग नहीं बदलनी।

**⚠️ एक ज़रूरी कदम:** Vercel पर फाइलें सेव नहीं की जा सकतीं (read-only filesystem),
इसलिए एडमिन पैनल के बदलाव सुरक्षित रखने हेतु **Blob storage** जोड़ना अनिवार्य है:

1. Vercel प्रोजेक्ट → **Storage** टैब → **Create Database** → **Blob** → Create
2. उसी प्रोजेक्ट से **Connect** करें (इससे `BLOB_READ_WRITE_TOKEN` अपने आप जुड़ जाता है)
3. **Redeploy** करें

Blob जुड़ते ही कंटेंट एवं अपलोड की गई फोटो Blob में सुरक्षित रहती हैं।
*Blob जोड़े बिना साइट दिखेगी तो सही, पर एडमिन पैनल में "सहेजें" काम नहीं करेगा।*

**अनुशंसित Environment Variables** (Vercel → Settings → Environment Variables):

| नाम | क्यों |
|---|---|
| `SESSION_SECRET` | कोई भी लंबा गुप्त शब्द — इसके बिना हर deploy पर लॉगिन टूट जाएगा |
| `ADMIN_USER` | एडमिन यूज़रनेम (डिफ़ॉल्ट `admin`) |
| `ADMIN_PASSWORD` | पहला पासवर्ड — केवल पहली बार खाता बनाते समय उपयोग होता है |

> कंटेंट बदलने के बाद वेबसाइट पर दिखने में अधिकतम 10 सेकंड लग सकते हैं (कैश)।
> एडमिन पैनल में बदलाव तुरंत दिखता है।

### VPS / Railway / Render / cPanel (Node.js App)

फाइलें अपलोड करें → `npm install` → `npm start` (या `pm2 start server.js`)।
यहाँ Blob की ज़रूरत नहीं — सब कुछ `data/` फोल्डर में सेव होता है।
**`data/` फोल्डर का नियमित बैकअप लें** — पूरा कंटेंट, संदेश एवं आवेदन उसी में रहते हैं।

> साधारण shared hosting (केवल PHP/HTML) पर यह CMS नहीं चलेगा।
